# 推豹子：表面偏地主规则下的正期望下注策略

[English README](README.md) | [中文研究报告](docs/report.zh-CN.md) | [English report](docs/report.en.md)

本项目最重要的结论有些反直觉：平局归地主，而且单个农民位置的胜率只有约 45.85%，所以规则表面上明显有利于地主。然而，农民以豹子获胜时获得二倍净收益，这一赔率足以补偿较低的胜率。完整牌堆下，对单个农民位置每下注 1 单位的精确期望收益为 `+0.0088988`，即约 `+0.8899%`。

本仓库进一步说明下注者如何在给定模型中把这一赔率优势转化为正的期望增长：观察剩余牌堆，在负期望状态停止下注，并根据三个农民位置的联合收益分布采用等额凯利仓位。项目包含连续四回合的精确状态枚举、条件收益分布、等额凯利比例和蒙特卡洛资金模拟。

这里的代码用于概率与优化研究，不构成赌博建议，也不承诺现实盈利。

## 游戏模型

- 牌堆共有 32 张牌：点数 1 至 8，每个点数各 4 张。
- 地主与三个农民位置每回合各获得 2 张牌。
- 豹子的点数为 `10 + 点数`；非豹子点数为 `(点数1 + 点数2) mod 10`。
- 平局由地主获胜。
- 农民非豹子获胜的净收益为 1 单位，豹子获胜为 2 单位，失败损失 1 单位。
- 连续发牌四回合后重置牌堆。

模型假设下注前可以准确知道每个点数的剩余张数。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `round1.m` 至 `round4.m` | 枚举牌堆状态和精确结果概率 |
| `compute_stds.m` | 计算波动率和夏普比率列 |
| `kelly_ratio.m` | 计算三个农民等额下注的凯利比例与对数增长 |
| `merge_kelly_results.m` | 生成资金模拟使用的策略查找表 |
| `simulate_player.m` | 在整数下注和桌面限额下模拟资金路径 |
| [`results/`](results/) | 经过校验的完整精确枚举表和精简策略查找表 |

仓库直接发布完整 CSV 结果，因此读者无需重新运行耗时的枚举即可检查每一种牌堆状态及其条件分布。旧的重复表、未完成的蒙特卡洛输出和生成图片仍不纳入版本控制。

## 环境要求

- MATLAB R2024a 或兼容的较新版本
- 当前实现不需要额外的 MATLAB 工具箱

## 复现分析

在仓库目录中运行：

```matlab
round1
round2
round3
round4

files = {'round1_results.csv', 'round2_results.csv', ...
         'round3_results.csv', 'round4_results.csv'};
for i = 1:numel(files)
    compute_stds(files{i});
    kelly_ratio(files{i});
end

merge_kelly_results
simulate_player(1000000, 25, 1)
```

精确枚举可能需要较长时间，第三回合尤其耗时。

完整结果快照、字段定义、校验和及数值校验摘要见 [`results/`](results/) 目录。

## 校验标准

每个生成的结果文件都应满足：

- 每轮所有牌堆状态的出现概率之和在浮点误差范围内等于 1；
- 每个牌堆状态下 27 种联合结果的概率之和约等于 1；
- 补齐为八位后的牌堆键不存在重复；
- 四轮结果文件分别包含 1、5,475、38,165 和 5,475 个状态。

已发布数据覆盖四轮共 49,116 个唯一牌堆状态。四轮按牌堆状态概率加权后的单农民期望收益均为 `0.0088987764`。

## 可复现性说明

`simulate_player` 会在 `final_wealth_stats.csv` 中记录模拟次数、四回合循环数、随机种子、初始资金、破产阈值、最大下注额和运行时间。在兼容的 MATLAB 版本中使用相同随机种子，可以复现相同的随机序列。

未完成的 Word 文稿和旧结果副本包含过时计算或模板身份信息，因此没有公开。历史蒙特卡洛资金结果也没有纳入，因为它们生成于“零下注时仍需推进牌堆”和“破产后永久退出”两项逻辑修复之前。

## 相关交互工具

[推豹子计算器](https://github.com/MegaKeqing/tuibaozi-calculator)（[在线体验](https://megakeqing.github.io/tuibaozi-calculator/)）是此前开发的浏览器端配套工具。它根据用户输入的剩余牌堆，通过蒙特卡洛模拟近似计算单回合胜率和期望收益。计算器采用与本项目一致的发牌和赔付规则，但其抽样估计不是本研究精确数值的来源。

本仓库负责精确枚举、完整联合分布和凯利分析；计算器适合交互探索与近似核对。后续可以让计算器对已覆盖的牌堆状态直接读取本仓库的精确查找表，仅在无法查表时回退到蒙特卡洛模拟。
